# Multi-Agent Harness Research Lab

Research repo for studying the market, patterns, and implementation details needed to build a multi-agent harness.

## Goal
- Map the market
- Compare existing harnesses and orchestration patterns
- Identify gaps/opportunities
- Turn the research into an implementation plan

## Working roles
- **Master Agent:** Herme
- **Research agents:** market scan, competitor analysis, architecture scan, evaluation scan

## Repo structure
- `research/` — notes and findings
- `agents/` — role definitions and prompts
- `plans/` — implementation plans
- `comparisons/` — competitor and feature matrices

## First questions
1. Which market segment is the target?
2. Which agents are essential for v1?
3. What does "good" mean: speed, quality, cost, autonomy, or all of them?
